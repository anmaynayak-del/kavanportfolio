# Kavan Portfolio

This is a portfolio project built with Vite and Three.js.

## How to run locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anmaynayak-del/kavanportfolio.git
   cd kavanportfolio
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the project:**
   Open your browser and navigate to the local host address provided in the terminal (usually `http://localhost:5173`).
